# 分阶段提示词示例

以下是可复用的复盘提炼，不是生成所有项目的固定指令。数量、主体、镜头与风格应按用户材料调整。

## 参考与设定

```text
依据我提供的参考图，整理同一主体的外观设定。保留轮廓、主要开口、附肢和材质特征，指出需要放大的关键部位。可见结构与遮挡推演分别说明。不要擅自改变主体类型。
```

## 三视图与内部关系

```text
绘制同一主体的俯视、侧视、正视参考，保持总长、部件站位和中性姿态一致，用中心线和首尾对齐线检查。按需另画内部剖视，解释壳体、骨架和通道关系；没有直接参考的内容标为推演。
```

## Blender 建模

```text
在 Blender 中建立可编辑模型。先搭主要体块、开口和连接，再补装甲、关节、窗口和表面细节。建立符合参考的环境、灯光和材质。保存工程与脚本，先提供实际预览，并从同一模型渲染正交三视图。
```

## 对照反馈

```text
这版的长度、宽度和部件位置与目标不一致。先归一化比较长宽高和关键部件站位，再修改实际网格。保留已经认可的设计。重新输出三视图与参考对照，说明改动及测量误差的具体范围。
```

## 运镜与额外角度

```text
沿用已确认模型、环境和动作。设计一个 10 秒镜头：低位接近主体，配合动作加速绕到侧面，再抬升收束。另做两个 5 秒视角：高位展示整体结构，低位突出体量。先展示完整运镜预览，再输出 1280×720、24fps 的原生动画。
```

## 过程视频

```text
把这次制作过程、每个阶段的真实图片、关键提示词和反馈整理成视频。先展示成片，再讲参考、建模、比例修正、细节和运镜，最后完整插入新角度。区分原始指令和复盘提炼，配清楚的中文标题、可读字幕与解说，输出封面和可复制的描述文案。
```
